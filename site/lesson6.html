楼龄与房价：房子越新越贵吗

直觉说：房子越新越贵。这一课我们用数据检验这个直觉——结果会推翻它，并且顺手学到整个统计学最重要的思想：相关不等于因果。

思维训练 约 25 分钟 本课产出：年代-房价对比图 + 一个反常识发现

本课目标

  • 学会把连续的年份切成"年代组"（pd.cut）
  • 学会算相关系数（corr）并读懂它
  • 理解三个统计思维大词：混杂变量、幸存者偏差、相关≠因果
  • 体验"提出假设 → 数据检验 → 推翻/修正"的完整研究循环

一步步做

1

先写下你的猜测（假设）

做分析前先明确猜测，是防止"看数据编故事"的好习惯。来，先投票：

假设 H：建成年份越新，房价越高

支持的理由：新房子设计好、贷款年限长、住着舒服。
反对的理由：老房子往往占着市中心和学区……

数据能不能验证？year_built 列有 7,106 个非空值（清洗后），足够做一次检验。开工，新建 step6_age.py：

2

把年份切成"年代组"

step6_age.py
import pandas as pd

df = pd.read_csv("toy_realestate_sample.csv", encoding="utf-8-sig")
df = df.drop_duplicates()
df = df[df["synthetic"] == 0]
df = df[df["price"].notna() & (df["price"] > 0)]

# 只保留有建成年份的行（.copy() 避免 pandas 的复制警告）
aged = df.dropna(subset=["year_built"]).copy()

# 把连续年份切成 5 个年代组，就像直方图的 bins 一样
bins = [0, 1990, 2000, 2010, 2020, 2030]
labels = ["1990前", "1990-1999", "2000-2009", "2010-2019", "2020后"]
aged["era"] = pd.cut(aged["year_built"], bins=bins, labels=labels, right=False)

era_stat = (
    aged.groupby("era", observed=True)
        .agg(n=("community_name", "count"),
             median_price=("price", "median"))
        .reset_index()
)
print(era_stat.to_string(index=False))

# 顺便算一下"年份"和"房价"的相关系数
print("\n相关系数：", round(aged["year_built"].corr(aged["price"]), 3))
era n median_price 1990前 140 4.8254 1990-1999 741 0.9000 2000-2009 2074 0.8194 2010-2019 2452 0.8725 2020后 1699 0.8800 相关系数： -0.138

⏸ 停一下，两个结果都出乎意料

① 最贵的居然是"1990 前"的老房子：中位 4.83 万/㎡，是其他年代的 5 倍多！年份跨过 1990 这条线，价格断崖式下跌，之后各年代挤在 0.82～0.90 万几乎不动。
② 相关系数是 -0.138——不是正的，是负的（虽然很弱）。也就是说：总体上，房子越新反而（略微）越便宜。

侦探时间：为什么老房子反而贵？

数据不会说谎，但需要解释。问一个问题：这些 1990 年前的老房子都在哪？

step6_age.py · 追加
# 查看 1990 年前小区的城市分布
old = aged[aged["year_built"] < 1990]
print(old["city"].value_counts().head(6))
天津 25 乌鲁木齐 21 上海 16 北京 12 南京 6 唐山 5 Name: city, dtype: int64

谜底揭开了一半。再补一刀——只看上海内部，楼龄和房价的相关性是多少？

step6_age.py · 追加
sh = aged[aged["city"] == "上海"]
print("上海内部相关系数：", round(sh["year_built"].corr(sh["price"]), 3),
      "，样本量：", len(sh))
上海内部相关系数： -0.024 ，样本量： 73

🎁 谜底：三个统计思维大词，一次凑齐

① 混杂变量："城市"在暗中捣乱——能留到今天还被挂牌的 1990 年前老房子，大多在天津（老洋房）、上海（如第 3 课见过的 1950 年"良友别墅"，26.5 万/㎡）、北京这些贵城市。看到"老房子贵"，其实你看到的是"贵城市的老房子贵"。一旦控制城市不变（只看上海），相关系数立刻从 -0.138 缩水到 -0.024，几乎归零。
② 幸存者偏差：普通县城的 1990 年前老破小早就没人挂牌、也不在数据里了；能在数据里"存活"的老房子，本身就是被核心地段和学区筛选过的佼佼者。
③ 相关≠因果："年份→价格"的相关系数是负的，但绝不意味着"把房子拆了重建就会变便宜"。它只描述了这份数据里的同时出现关系，不承诺因果。
