第 8 课 / 共 8 课

地理可视化：画出房价"星空图" + 结课

收官一课做最好玩的事：数据里有 11,060 个小区带经纬度坐标，我们把每个小区当成一颗星星画在图上，用颜色表示价格——不用任何地图软件，一张散点图就能"看见"中国的房价版图，甚至能看见一条著名的地理分界线。

成果收官 约 25 分钟 本课产出：房价星空图 + 后续学习路线

本课目标

  • 学会画带颜色映射的散点图（scatter + colorbar）
  • 理解为什么价格上色要用"对数刻度"
  • 从图里读出地理结构：城市群、价格断层、胡焕庸线
  • 规划结课之后的学习方向

一步步做

1

准备带坐标的数据

先回顾第 2 课的原则——按需清洗：画地图只要求行里有经纬度，其他列缺不缺无所谓：

step8_geo.py
import pandas as pd
import numpy as np                     # numpy：数值计算工具，pandas 的好搭档

df = pd.read_csv("toy_realestate_sample.csv", encoding="utf-8-sig")
df = df.drop_duplicates()
df = df[df["synthetic"] == 0]
df = df[df["price"].notna() & (df["price"] > 0)]

# 只保留有经纬度的行（约 73.5%）
geo = df.dropna(subset=["longitude", "latitude"]).copy()
print("带坐标的小区：", len(geo))
带坐标的小区： 11060
2

画星空图（关键：对数上色）

直接用 price 上色有个问题：价格从 0.1 万到 41 万跨度 400 倍，几乎所有点都会挤在最暗的那一档。对数刻度能把"1000 与 41000 的差距"压缩成"3 与 4.6 的差距"，让贵的点亮起来而不淹没便宜的点：

step8_geo.py · 追加
import matplotlib.pyplot as plt

plt.rcParams["font.sans-serif"] = ["Microsoft YaHei", "PingFang SC", "SimHei"]
plt.rcParams["axes.unicode_minus"] = False

fig, ax = plt.subplots(figsize=(8.6, 5.4))
sc = ax.scatter(
    geo["longitude"], geo["latitude"],      # x=经度，y=纬度
    c=np.log10(geo["price"]),             # 颜色 = 价格取对数
    cmap="viridis",                        # 配色方案：暗紫→亮黄
    s=2.2, alpha=0.55, linewidths=0,     # 点很小、半透明，防止糊成一团
)
cbar = fig.colorbar(sc, ax=ax, shrink=0.85)
cbar.set_label("挂牌单价（万/㎡，对数刻度）")
ax.set_xlabel("经度")
ax.set_ylabel("纬度")
ax.set_title("11,060 个小区的地理分布（颜色越亮越贵）")
plt.tight_layout()
plt.savefig("geo_scatter.png", dpi=150)
plt.show()
3

读图：三分钟看懂中国房价版图

这张图至少能读出四层信息

① 城市轮廓浮现：点密集的地方就是城市群——长三角、京津冀、珠三角、成渝清晰可辨；小亮点是省会和区域中心。

② 最亮的在三处：看最黄最亮的点团：北京、上海、深圳/东莞（以及长三角的苏州-杭州带）。第 4 课的 Top15 排行在地图上被"照亮"了一遍——排行榜和星空图互为印证。

③ 西部大片暗区：不仅点稀疏，而且颜色偏暗——对应第 4 课"最便宜 10 城"清一色西部州县。价格的空间格局和排行榜完全一致。

④ 一条隐形的线：从东北黑龙江到西南云南画一条线，线的东南侧星星密集成片，西北侧几乎空白——这就是地理学著名的胡焕庸线（黑河—腾冲线）。我们只画了房价数据点，中国人口地理的大结构却自己浮现出来。好可视化就是有这种"顺手揭示大格局"的力量。

彩蛋：为什么不上真地图？

想让点真正落在地图上，可以用 folium（交互地图）或 plotly，它们能加载在线底图。但作为入门，纯散点图零依赖、秒出图，已经能回答"哪里贵、哪里密"的问题。先解决问题，再追求华丽——这也是工具选择的哲学。

下一步去哪

① Jupyter Notebook

把"写代码-看结果"融在一个页面里的笔记本，数据分析的标配环境。python -m pip install notebook 后运行 jupyter notebook。把 8 课的代码搬进去逐格重跑一遍，是最好的复习。

② seaborn 美化图表

基于 matplotlib 的"美颜滤镜"，一行 sns.histplot(df["price"]) 就出精致统计图。python -m pip install seaborn 即装即用。

③ 真地图 folium

把第 8 课的星空图升级成交互地图，能缩放、能点出每个小区的名字。教程彩蛋里那些经纬度坐标直接就能用。

④ 机器学习

当你会熟练清洗数据、看懂相关关系之后，就够到机器学习的门槛了：用 scikit-learn 拿这份数据预测价格、聚类小区。记住：数据和特征决定上限，模型只是逼近上限。

完整代码合集

本教程 8 课用到的全部代码（含出图脚本的完整版）都整理在 complete_analysis.py，约 200 行，带中文注释。把它保存下来，日后当成自己的"分析模板"改着用。
