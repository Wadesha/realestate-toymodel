准备工作：让电脑能跑 Python

这一课不分析任何数据，只做一件事：把"工具"装好，并让你第一次亲手把 15,346 行房价数据读进电脑。装好后，后面 7 节课都不用再装任何东西。

零基础起点 约 30 分钟 本课产出：屏幕打印出数据前 5 行

本课目标

  • 在自己的电脑上装好 Python（编程语言）和 pandas（数据处理工具）
  • 建一个专门放练习的文件夹，把数据文件放进去
  • 写出并运行人生第一个数据分析脚本
  • 看懂这份数据的 18 个字段分别是什么意思

先搞懂三个词

Python

一门编程语言，也是数据分析领域最常用的语言。你写几行指令，电脑照着执行。我们全程只用"照抄代码"的方式使用它。

pandas

Python 的一个"外挂包"，专门处理表格数据。装了它，读 CSV、算平均值、排序都只要一行代码。名字来自 panel data（面板数据），和熊猫没关系。

CSV 文件

最通用的表格文件格式：纯文本，每行一条记录，逗号分隔各列。用 Excel 能打开，但 15,346 行用 Excel 筛选汇总会很卡——这正是我们要学 pandas 的原因。

一步步做

1

安装 Python

打开浏览器，访问 Python 官网下载页：

下载地址
https://www.python.org/downloads/

点击黄色的 Download Python 3.x.x 按钮，下载后双击安装。

⚠️ Windows 用户必看（最容易踩的坑）

安装第一页的底部有一个勾选框 Add python.exe to PATH——一定要勾上！不勾的话，以后在命令行里输入 python 会提示"不是内部或外部命令"。如果已经装完才发现没勾：重新运行安装包，选 Modify，再把勾打上即可。

2

验证安装成功

打开"命令行"（就是那个能输入命令的黑窗口）：

  • Windows：按键盘 Win + R，输入 cmd，回车
  • Mac：按 Command + 空格，输入"终端"或 Terminal，回车

在黑窗口里输入下面的命令，回车：

命令行
python --version
Python 3.12.4

能打印出 Python 3.x.x 字样就说明成功了（x 是几无所谓，只要开头是 3）。如果提示"不是内部或外部命令"，回去检查第 1 步的 PATH 勾选。

3

安装 pandas

继续在命令行里输入（这一步要联网，等待 1–2 分钟）：

命令行
python -m pip install pandas

看到 Successfully installed pandas-x.x.x ... 就装好了。

为什么要加 python -m ？

直接输入 pip install pandas 有时会报"pip 不是内部命令"；写成 python -m pip 的意思是"用刚装好的那个 Python 自带的 pip"，对初学者最稳。第 3 课要画图，到时再装 matplotlib，方法相同。

4

建练习文件夹

在你容易找到的地方（比如"文档"目录下）新建一个文件夹，取名 house-analysis（名字随意，不要用中文和空格更省心）。然后把数据文件复制进去：

house-analysis/ └── toy_realestate_sample.csv ← 数据文件（约 4 MB）

接下来 8 节课的所有代码文件，都保存在这个文件夹里。代码文件和数据文件放同一个文件夹，是后面代码能直接运行的秘诀。

5

写下第一个脚本

用任意文本编辑器新建一个文件（Windows 自带的"记事本"就行，推荐以后装免费的 VS Code），粘贴下面的代码，保存为 step1_load.py（注意扩展名是 .py 不是 .txt），放进刚才的文件夹：

step1_load.py
import pandas as pd                    # 载入 pandas 工具，简写为 pd

# 读取 CSV 文件。encoding="utf-8-sig" 是为了正确处理文件开头的隐藏字符
df = pd.read_csv("toy_realestate_sample.csv", encoding="utf-8-sig")

# df 就是装着 15,346 行数据的"表格"，下面问它三个问题：
print("数据有多少行、多少列：", df.shape)
print("一共有多少个城市：", df["city"].nunique())
print("\n前 5 行长这样：")
print(df.head())

逐行解释

import pandas as pd：把工具箱搬进来，以后都叫它 pd。
pd.read_csv(...)：读取文件，变成 pandas 的表格对象（叫 DataFrame，简称 df）。
df.shape：表格的形状（行数, 列数）。
df["city"].nunique()：city 这一列有多少个不同的值（去重计数）。
df.head()：看前 5 行，快速认识数据长什么样。

6

运行它！

在命令行里，先把位置"切"到你的文件夹（把下面的路径换成你自己的），再运行：

命令行（Windows 示例）
cd C:\Users\你的用户名\Documents\house-analysis
python step1_load.py

按下回车，你会看到（这就是本教程真实运行的结果，你的应该一模一样）：

附：18 个字段都是什么意思

分析数据前必须先认识数据。这张表建议收藏，后面每课都会用到。

字段含义例子 / 说明
city城市济南、上海、深圳……共 209 个
community_name小区名绿地IFC中央公馆B7地块
district区县（可能带年份前缀）"2023历下"——注意这个前缀，第 2 课要处理它
subdistrict商圈 / 片区CBD、全运村
road道路齐音路
nearby周边配套标签"近地铁,近学校,别墅"（缺失最多的一列，约 7804 行没有）
price挂牌均价（万/㎡）2.5581 = 25,581 元/㎡，全教程的主角
price_yuan挂牌均价（整数元/㎡）25581，和 price 是同一信息的两种单位
original_price原始价格文本"25581 元/m²"（网页上原样抓下来的）
price_change价格涨跌幅"0.28%"，也可能是"持平"（不是数字，第 2 课处理）
secondhand_count该小区二手房挂牌套数5
rent_count该小区租房挂牌套数21
year_built建成年份2023；约 8000 行没有这个信息
fetch_date数据抓取日期2026-05-27
detail_links原网页链接文本分析用不到，纯留档
longitude经度117.10（约 73.5% 的行有坐标）
latitude纬度36.67
synthetic是否为合成数据0=真实抓取，1=合成补位（第 2 课要用它过滤）

常见报错急救表

初学阶段 90% 的卡壳都在这四行里。报错时先来这里对号入座。

报错信息原因解决办法
No such file or directory: 'toy_realestate_sample.csv'CSV 不在当前文件夹，或文件名打错确认 CSV 和 .py 在同一文件夹；命令行 cd 到该文件夹再运行
ModuleNotFoundError: No module named 'pandas'pandas 没装上，或装到了别的 Python 里用 python -m pip install pandas 重装（注意是哪个 python 就用哪个 -m）

课后练习（做完才算学会）

  1. 把 df.head() 改成 df.tail(3)，看看数据的最后 3 行长什么样。
  2. 用一行代码算出：数据里最贵的小区单价是多少万/㎡？（提示：df["price"].max()）
  3. 数一数数据里出现了多少个不同的小区名。（提示：把练习 1 里的 head 换成 nunique 就行……不对，是把 df.head() 换成对 community_name 这一列数）
点开看参考答案 
print(df.tail(3))                      # 练习1
print(df["price"].max())                # 练习2 → 41.4545（万元/㎡，后面课程会见到它）
print(df["community_name"].nunique())   # 练习3 → 13091（有小区同名，去重后 1 万多个）
