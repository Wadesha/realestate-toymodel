第一个分析：全国房价长什么样

数据洗干净了，正式开始分析。这一课用两个最基础的动作——"统计描述"和"直方图"——回答一个问题：把全国 15,035 个小区放在一起看，房价是什么样子？ 你会发现一个反直觉的事实：平均数居然是中位数的两倍多。

第一张图 约 25 分钟 本课产出：房价分布图 + 最贵小区 Top10

本课目标

  • 学会用 describe() 五分钟给一列数据"摸底"
  • 搞懂平均数和中位数的区别——为什么说房价要用中位数
  • 安装 matplotlib，画出人生第一张直方图
  • 从 Top 榜里练出"用常识审视结果"的习惯

一步步做

1

五分钟摸底：describe()

新建 step3_overview.py。前几行是老朋友（读文件 + 第 2 课的清洗），保证你每课都能独立运行：

step3_overview.py
import pandas as pd

df = pd.read_csv("toy_realestate_sample.csv", encoding="utf-8-sig")
df = df.drop_duplicates()
df = df[df["synthetic"] == 0]
df = df[df["price"].notna() & (df["price"] > 0)]

# 一行代码，给价格列做全面体检
print(df["price"].describe())
count 15035.000000 mean 1.310425 std 2.315333 min 0.100000 25% 0.460150 50% 0.610000 75% 1.000000 max 41.454500 Name: price, dtype: float64
输出项含义本数据的值
count有多少个有效数字15,035 个小区
mean平均数1.31 万/㎡
std标准差（波动有多大）2.32（比平均数还大，说明极度分散）
min / max最小 / 最大值0.10 万 ～ 41.45 万，相差 400 倍
25% / 50% / 75%四分位数一半小区在 0.46～1.00 万之间

⏸ 停一下：这里藏着一个大发现

平均数 1.31 万，中位数（50% 那行）只有 0.61 万——平均数是中位数的 2.1 倍！

想象一个房间里站着 10 个人，9 个是普通打工人，1 个是首富——"平均收入"会被首富一个人拉上天，但"中位收入"（从低到高排，站中间那位）几乎不变。房价同理：少数 10 万+ 的豪宅把平均数拉高了一倍，而中位数 0.61 万/㎡ 才代表"典型小区"的价格。

这就是"偏态分布"。以后凡是看到"平均工资""平均房价"，你都要多问一句：中位数是多少？

2

画出来：第一张直方图

数字表格不够直观，我们画直方图：把 0～3 万切成 40 个格子，数每个格子里落了多少小区。先装画图工具（命令行里运行一次即可，之后所有课共用）：

命令行
python -m pip install matplotlib

然后在 step3_overview.py 末尾追加：

step3_overview.py · 追加
import matplotlib.pyplot as plt

# 让图表能显示中文（Windows 用微软雅黑，Mac 用苹方）
plt.rcParams["font.sans-serif"] = ["Microsoft YaHei", "PingFang SC", "SimHei"]
plt.rcParams["axes.unicode_minus"] = False

# 只画 0~3 万的部分（覆盖 92.3% 的小区，太贵的挤成一团看不见）
data = df[df["price"] <= 3]["price"]

plt.hist(data, bins=40, color="#2563eb", edgecolor="white")
plt.axvline(df["price"].median(), color="#dc2626", linestyle="--",
            label=f'中位数 {df["price"].median():.2f} 万')
plt.axvline(df["price"].mean(), color="#f59e0b", linestyle="--",
            label=f'平均数 {df["price"].mean():.2f} 万')
plt.xlabel("挂牌均价（万/㎡）")
plt.ylabel("小区数量（个）")
plt.title("全国 15,035 个小区的挂牌单价分布")
plt.legend()
plt.tight_layout()
plt.savefig("price_dist.png", dpi=150)   # 保存成图片文件
plt.show()                                                  # 弹窗展示

为什么中文显示成方框？

matplotlib 默认不带中文字体。上面那两行 plt.rcParams[...] 就是在指定用系统自带的中文字体（Windows: 微软雅黑 / Mac: 苹方）。以后每张图都要带上这两行，忘了就会看到一排"口口口"。

运行后，会弹出一个窗口，同时文件夹里多出一个 price_dist.png。本教程官网上的版本长这样（同一个代码、同一份数据跑出来的）：

怎么读这张图

· 横轴是价格（万/㎡），纵轴是这个价格段有多少小区；
· 最高峰在 0.4～0.7 万之间——全国最"典型"的房价就是六七千一平米；
· 我们截断在 3 万，因为超过 3 万的小区只占 7.7%，但最贵到 41 万——这条"长尾"正是平均数被拉高的元凶。

🔍 用常识审视结果（分析师的第二天性）

盯着这份榜单看 10 秒，你能发现三件事：

① 全是别墅——顶级价格的世界里没有普通住宅。买不起，但分析时要想到：别墅的单价逻辑（稀缺、大面积）和普通住宅完全不同。
② "香山美墅""双玺时光道"同时出现在深圳和东莞，价格一模一样——数据源把临深片区的房源同时挂到了两个城市名下。这是数据的小毛病，好在只影响极少数行。
③ 上海"良友别墅"建于 1950 年，75 年房龄还卖出 26.5 万/㎡——记住它，第 6 课讲楼龄与房价时它会再次登场，并且会推翻一个直觉。
